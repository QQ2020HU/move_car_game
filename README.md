# 堵车大作战（又称：统统闪开）

微信小游戏 · 挪车解谜（经典滑块 / Rush Hour 玩法）。
按《微信小游戏挪车解谜开发文档.md》V1.0 实现的 MVP 版本。

## 玩法

停车场（6×6 起步，后期关卡扩大到 7×7 / 8×8），车辆占 2~3 格，只能沿自身方向拖动；
黄色斜纹**禁停区**不可通行。把**红色目标车**从右侧绿色出口开出即通关（出口栏杆会自动抬杆）。
无法移动或撞上其他车辆时会**鸣笛 + 双闪**提示。步数越少星级越高：

- ★★★：步数 ≤ `parMoves`
- ★★：步数 ≤ `parMoves + 3`
- ★：通关

每 6 关切换一个**全屏场景主题**（驾校 🚧 → 小区 🏘 → 商场 🛒 → 医院 🏥 → 机场 ✈️）：
整屏天空/墙面/远景/道具全部重绘并带轻量动画（驾校蓝天锥桶与教练车巡游、小区晚霞亮灯楼群、
商场店铺遮阳篷与气球、医院红十字灯箱与心电图、机场星空塔台与起降飞机），
棋盘地面配色随主题变化，同一章节内每关道具布局也有差异。
首次进入新章节弹出**章节过场卡片**（存档记忆，只弹一次，点按跳过）；
目标车**完全堵死时头顶冒「😤」气泡，出口通路打开后变「😄」**。

第 11 关起每关有**步数上限**（约 par 的 1.8~2 倍，撤销退还步数，前 10 关教学期不限步）；
步数耗尽进入**失败结算**，可看激励视频（广告不可用时自动免费）或花 150 金币**复活续走**，
棋盘保持现状。通关结算页可观看 **👻 最优解幽灵回放**——solver 验证过的解法用实机同款
吸附/出库动画演一遍（不计步，轻点任意处跳过）。主菜单 🛒 **涂装商店**可用金币购买
6 套车身涂装皮肤（纯外观色板，购入即装备，可随时切换）。

## 技术栈

**原生微信小游戏（Canvas 2D + 原生 JS 模块）**，零第三方依赖。

> 文档建议 Cocos Creator 3.8 + TypeScript。因 Cocos 项目必须由编辑器（GUI）
> 创建场景并构建，无法在当前环境交付可验证产物，经确认改用原生小游戏实现。
> 文档中的模块划分、状态机、数据结构、规则语义全部保留；
> 核心规则引擎为纯逻辑 CommonJS 模块，可直接在 Node 中单元测试。

## 关卡设计

- 第 1~10 关：手工设计 6×6 教学关，par 2~5，新手曲线。
- 第 11~16 关：6×6 + 禁停区（obstacles），par 6~9。
- 第 17~23 关：7×7 大型停车场 + 禁停区，par 9~13。
- 第 24~30 关：8×8 超大型停车场 + 多禁停区，par 11~16（车辆 13~17 台）。
- 棋盘尺寸、禁停区数量、parMoves 三重递增构成难度曲线；
  每关的 `parMoves` 与 `solution` 均由 BFS 求解器计算并经过重放验证，
  供三星评价与提示系统使用。

## 已知限制

- `project.config.json` 的 appid 为开发者工具写入的测试 AppID，提交审核前需替换为正式小游戏 AppID。
- 车辆美术为程序化精灵（零图片资源），如需更高品质可替换为正式美术贴图；音效为 WebAudio 实时合成，如需更真实可替换为音频文件。
- 数据统计仅写本地日志，未接入合规上报。
- 上线检查清单中的平台合规项（备案、类目、隐私说明）需在微信公众平台完成。
